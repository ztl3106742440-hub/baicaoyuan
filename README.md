# 百草园

《百草园》是一个面向考研英语一的公开学习 PWA，当前以写作学习为主，并保留难词学习模块。

## 在线使用

GitHub Pages：<https://ztl3106742440-hub.github.io/baicaoyuan/>

打开网页后，可通过浏览器的“安装应用”或“添加到主屏幕”功能安装到 Android 手机。首次完整加载后，主要页面与教材支持离线阅读。

## 当前内容

- Part A 小作文：任务识别、母版、功能句、题卡与逐句解析。
- Part B 大作文：图画、图表、混合材料、论证逻辑、功能句与主题卡。
- 单词模块：已接入首批 5 词校准数据，默认提供一词一卡主动回忆，并支持 10/20/30 词组卷、每页 30 词的分页词库、折叠详情、助记与辨析，以及“不会 / 模糊 / 认识”和收藏状态。
- 学习导航：作文和单词均提供左侧功能栏、手机抽屉、一键收起全部展开内容和当前分页双击回顶；搜索、数据与主题等次要工具放在侧栏底部。
- 教材与记录：支持下载当前作文教材，以及导出、导入本地学习记录。

## 数据边界

公开仓库只包含网页成品和公开教材。掌握状态、阅读位置和其他个人学习记录保存在使用者自己的浏览器中，不会上传到 GitHub。

当前教材仍标记为 `draft + unverified`，适合作为个人学习与内容校准版本，不应被描述为已经完成外部事实核查的正式出版物。

## 更新方式

每次仓库主分支更新后，GitHub Actions 会自动发布最新网页。已安装的 PWA 会检测到新的 Service Worker，并提示刷新更新。

## 技术形式

纯静态 HTML、CSS、JavaScript、JSON、IndexedDB 与 Service Worker；无后端账号系统，无服务器端个人数据存储。
