# 百草园

《百草园》是一个面向考研英语一的公开学习 PWA，当前以写作学习为主，并保留难词学习模块。

## 在线使用

GitHub Pages：<https://ztl3106742440-hub.github.io/baicaoyuan/>

打开网页后，可通过浏览器的“安装应用”或“添加到主屏幕”功能安装到 Android 平板或手机。首次完整加载后，主要页面与教材支持离线阅读；平板是当前日常背诵主终端。

## 当前内容

- Part A 小作文：9 个学习章节；首章集中训练建议邮件、招募通知、邀请和回复，后续把审题、母版、10 类主体场景、36 组 A/B 句式中的 A 部分、7 篇原创范文和反向训练接成一条学习链。
- Part B 大作文：8 个学习章节；首章集中训练图画与图表母版，后续把材料审题、8 条论证链、B 部分句式、2 篇原创范文和反向训练接成一条学习链。
- 核心背诵：提供“核心母版 / 跨题迁移 / 填槽训练 / 加分句 / 自测”五种局部模式，一次只显示一种任务；迁移案例和答案不会全部纵向铺开。
- 英文审题：15 个 V7.1 专题嵌入原有章节，通过局部选项卡与折叠阅读；练习答案默认隐藏。
- 写作阅读：一次只打开一个章节；母版与题卡每页 1 条、功能句每页 4 条、主题卡每页 2 条。V7.2 场景、论证、范文和训练各自一次只显示一项，并可沿“母版 → 主体素材 → 功能句 → 范文 → 自测”继续。
- 单词模块：已接入第一部分 752 词正式数据，默认提供一词一卡主动回忆，并支持 10/20/30 词组卷、每页 30 词的分页词库、折叠详情、助记与辨析，以及“不会 / 模糊 / 认识”和收藏状态。复习按到期、新词、补充复习排序，并采用 1/3/7/14/30/60/120 天间隔。
- 词汇关系网：第二部分共 69 组、493 个学习节点，按语义边界、词形、搭配、熟词生义和命题替换分类，每页 10 组，并提供原创微测试。
- 阅读专题：第三部分共 26 个专题、52 道原创题；每次显示一个专题，提交后才显示答案、证据句与干扰项诊断，完成状态保存在本机。
- 学习导航：作文和单词均提供左侧功能栏、手机抽屉、一键收起全部展开内容和当前分页双击回顶；写作页另有固定章节条和章内上一组/下一组，搜索、数据与主题等次要工具放在侧栏底部。
- 教材与记录：支持下载当前作文教材；本机记录导出、补充导入只是可选保险，不承担跨设备同步。

## 数据边界

公开仓库只包含网页成品和公开教材。掌握状态、阅读位置和其他个人学习记录只保存在当前浏览器中，不会上传到 GitHub，也不会在平板、手机和电脑之间自动同步。

当前 752 个单词已经通过结构、引用和移动展示验收，标记为 `ready + unverified`。关系网与阅读专题已通过 Schema、ID、证据句、交叉链接和答案索引校验，仍保留为 `draft + partially-source-checked`；原 80 个作文实体仍为 `draft + unverified`，V7/V7.1/V7.2 三个覆盖层为 `ready + unverified`。V7.2 原创范文已保留来源包的内部审阅标记，但结构校验和页面可用仍不等于独立事实核查。

## 更新方式

每次仓库主分支更新后，GitHub Actions 会自动发布最新网页。已安装的 PWA 会检测到新的 Service Worker，并提示刷新更新。

## 技术形式

纯静态 HTML、CSS、JavaScript、JSON、IndexedDB 与 Service Worker；无后端账号系统，无服务器端个人数据存储。
