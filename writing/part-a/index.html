02

READ · DECIDE · WRITE

审题与体裁：60 秒判断写什么

把原来的“认识小作文、五步审题、功能与体裁”合在一章：先定对象和任务，再定邮件或通知，最后列出必须回答的信息。

01

TASK & FORMAT

先定任务，再选表达容器

邮件 / 书信

面向明确收件人

称呼、目的、必答信息和礼貌结尾相互配合，语气随关系变化。

通知 / 告示

面向一组读者

标题、时间、地点、对象、报名或联系信息应清楚，不硬套书信落款。

判断原则不要只看题型名称；先回答“我在对谁、为了什么、必须说哪几件事”。
02

FIVE CHECKS

五步拆题

  1. 收信人同学、老师、机构或公众？
  2. 写作目的邀请、建议、回复、说明还是通知？
  3. 必答任务把题干动词拆成可核对清单。
  4. 语气正式程度与关系匹配。
  5. 格式称呼、正文、落款或通知要素。
点击展开 · 典型陷阱
  • 写了漂亮寒暄，却漏掉题干要求的具体安排。
  • 把“回复说明”误当成一种与邮件并列的固定格式。
  • 题目没给时间地点，却从背过的范文里整段搬运。
  • 为了显得正式，把朋友邮件写成外交照会。
03

FUNCTION × FORMAT

功能与体裁交叉判断

功能邮件 / 书信通知 / 告示
邀请与安排说明活动、时间与回应方式面向群体发布安排
建议与推荐依据对方需要给可操作建议通常不是首选体裁
回复与说明回应来信并补齐必答信息用于公开澄清时才成立
通知与招募可向个人发送，但仍属邮件时间、地点、资格、报名方式
询问 / 道歉 / 感谢围绕具体关系与事件仅在公开场景按题意使用
